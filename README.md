## Projetos em destaque

### GoOut

Aplicação voltada para descoberta de **eventos culturais, shows e atividades**, utilizando localização, categorias, filtros e recomendações para ajudar o usuário a encontrar experiências de acordo com seu perfil e situação.

**Tecnologias:** React • TypeScript • Node.js • Banco de dados

---

### SIGA

Aplicativo desenvolvido com foco em **informações relacionadas à coleta de resíduos**, buscando facilitar o acesso da população às informações sobre o serviço e contribuir para uma melhor organização da coleta.

**Tecnologias:** Desenvolvimento Web • Banco de dados • APIs

---

### Projeto Bancário

Aplicação desenvolvida para apresentar uma alternativa de crédito, com uma interface moderna e foco em uma experiência simples para o usuário.

**Tecnologias:** React • Vite • Bootstrap • JavaScript

---

### Aplicativo de Reciclagem

Aplicação mobile voltada para **educação e descarte correto de resíduos**, incluindo localização de pontos de reciclagem e informações sobre como separar diferentes tipos de lixo.

**Tecnologias:** Flutter • Dart • Geolocalização • Maps
